# 中国大陆壁纸来源与来源分组调整设计

## 背景

当前 Wallhaven 与 Civitai 共享“AI 与壁纸”分组，来源语义不清。节点需要增加稳定的中国大陆壁纸来源，同时保持每个来源的抓取、解析、分页、详情和下载策略独立，避免新增站点时修改一个集中式大类或影响已有 Provider。

## 目标

- 将 Wallhaven 移到独立的“壁纸”分组。
- 新增彼岸图网（`pic.netbian.com`）和壁纸网（`bizhi99.com`）。
- 两个来源支持公开 HTML 列表分页、分类筛选、详情查看、原图下载、缓存和现有前后页操作。
- 保留来源页、标题、尺寸、作者或页面说明等可获得的公开信息。
- 下载只允许各来源声明的官方图片域名，拒绝跨站跳转和非图片响应。
- 不接入需要登录、绕过验证、依赖浏览器自动化或当前无法稳定访问的站点。

## 非目标

- 不把两个站点抽象成一个负责所有站点差异的总管家类。
- 不抓取搜索引擎结果、用户私有内容或需要登录的下载接口。
- 不承诺图片本身的再发布权利；界面继续展示来源和版权提示。
- 本轮不接入极简壁纸、4K Wallpaper、Wallpaper Show。

## 来源分组

来源自行声明 `ProviderPresentation`：

| 分组 | 来源 | 分组顺序 |
| --- | --- | ---: |
| AI 与生成 | Civitai | 10 |
| 壁纸 | Wallhaven、彼岸图网、壁纸网 | 15 |
| 摄影与设计 | Behance、Feature Shoot、Aperture 等 | 20 |
| 艺术馆藏 | V&A、芝加哥艺术博物馆、克利夫兰艺术博物馆、LOC、NASA | 30 |
| 电影 | FilmGrab | 40 |
| 本地 | 本地历史 | 50 |

Wallhaven 只改变展示分组，不改变其请求参数、SFW 约束、榜单范围或下载目录。

## Provider 结构

新增两个独立模块：

- `src/ty_image_spider/providers/netbian.py`
- `src/ty_image_spider/providers/bizhi99.py`

每个模块实现 `AssetProvider` 所需的 `descriptor`、`status`、`search`、`detail` 和 `download`，并拥有自己的：

- 分类到站点路径的映射。
- 页码游标校验。
- 列表页和详情页 HTML 解析器。
- 图片地址规范化和尺寸提取。
- 来源域名下载策略。
- 缓存键命名空间。

公共下载安全策略继续复用 `DownloadPolicy`、`CuratedDownloader` 和现有图片类型校验。Provider Registry 只负责注册和查找，不承担来源差异。

## 彼岸图网

- ID：`netbian`
- 展示：`彼岸图网`
- 分组：`wallpaper` / `壁纸`
- 列表入口：最新、4K 风景、4K 动漫、4K 剧照、4K 汽车、4K 动物、4K 背景、4K 手机、5K 带鱼屏。
- 分页：使用来源页码路径，游标只接受正整数。
- 详情：解析标题、原图地址、分辨率和来源页；无法取得作者时不伪造作者。
- 下载白名单：`pic.netbian.com` 及其图片子域名中实际验证过的主机。
- 缓存：列表页和详情元数据进入 `cache/netbian/`，原图按需下载到 `output/ty-node/ty-image-spider/netbian/`。

## 壁纸网

- ID：`bizhi99`
- 展示：`壁纸网`
- 分组：`wallpaper` / `壁纸`
- 列表入口：最新、风景、星空、动漫、背景、萌宠、汽车、游戏、影视剧照、小清新。
- 分页：使用来源页码路径，游标只接受正整数。
- 详情：解析标题、原图地址、分辨率和来源页；保留站点公开的分类信息。
- 下载白名单：`bizhi99.com` 和站点声明的静态图片主机；若实际图片来自未验证主机，Provider 返回可解释错误，不放宽白名单。
- 缓存：列表页和详情元数据进入 `cache/bizhi99/`，原图按需下载到 `output/ty-node/ty-image-spider/bizhi99/`。

## 搜索与分页契约

- 空关键词按当前分类浏览。
- 关键词只用于来源支持的公开页面筛选；不拼接未经编码的 URL。
- 第 1 页使用空游标，下一页游标为来源页码字符串，上一页由前端已有游标栈恢复。
- 解析不到有效图片时跳过该条目；整页没有有效图片时返回来源错误或空结果的明确状态。
- 请求失败时沿用现有缓存回退规则，不把旧缓存伪装成实时结果。

## UI 与详情

- 来源导航新增“壁纸”分组，组内按 `source_order` 显示 Wallhaven、彼岸图网、壁纸网。
- 来源卡片显示来源短标记，详情标题使用来源长名称。
- 详情弹窗显示来源页链接、标题、分辨率和可用分类。
- 全屏查看、滚轮缩放、拖拽、键盘左右切换和保存行为复用现有通用组件。

## 测试验收

- 缓存命名空间和来源切换测试。

- 来源导航显示独立“壁纸”分组。
- 三个壁纸来源切换后各自保留筛选、图片和分页位置。

发布前运行完整 Python 测试、前端测试和格式检查，并对两站各做一次只读真实列表探测。

## 权利与运行边界

节点只读取公开页面和图片地址，遵守来源 robots 与访问限制，使用现有限速、缓存和失败回退。下载按钮表示用户主动保存，不代表图片获得再发布许可；详情中保留来源链接，README 和来源说明继续提醒用户自行确认版权与站点条款。
