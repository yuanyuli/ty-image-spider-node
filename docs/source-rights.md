# 素材来源与使用权利

项目代码采用 MIT；该许可不涵盖外部图片、提示词、商标、馆藏资料或电影静帧。公开浏览、下载和本地缓存均不改变素材许可。商业使用、再分发或训练用途请核对原作品和来源条款；本节点不作授权判断。

| 来源 | 数据入口与权利核对 |
| --- | --- |
| Civitai（含 civitai.red） | 公开图片 API 与详情页；核对作者、模型及作品许可，镜像可访问不产生额外授权。[主站](https://civitai.com/) |
| Wallhaven | [公开 API](https://wallhaven.cc/help/api)；上传者不一定拥有版权，优先核对原始来源和作者。 |
| Behance | [公开作品页](https://www.behance.net/)；保留项目与创作者链接，公开作品集不等于商业授权。 |
| Colossal | [公开专题](https://www.thisiscolossal.com/)；核对专题中摄影师、艺术家署名和原作链接。 |
| Design Milk | [公开专题](https://design-milk.com/)；图片权利归相应作者及权利方。 |
| Feature Shoot | [摄影专题](https://www.featureshoot.com/)；核对摄影师及代理机构授权。 |
| My Modern Met | [公开专题](https://mymodernmet.com/)；原作者、转载许可和专题版权须分别核对。 |
| Aperture | [摄影作品与杂志](https://aperture.org/)；摄影与编辑内容可能分别受许可保护。 |
| PRINT Magazine | [设计专题](https://www.printmag.com/)；保留设计师、项目和来源链接。 |

| NASA Image Library | [官方图片库](https://images.nasa.gov/)；核对 [媒体使用规范](https://www.nasa.gov/nasa-brand-center/images-and-media/)，第三方署名、人物肖像和标识可能另有限制。 |
| FilmGrab | [电影静帧](https://film-grab.com/)；电影画面通常受版权保护，网站收录不等于提供商用许可。 |
| V&A | [馆藏接口](https://developers.vam.ac.uk/)；逐项核对馆藏页及图像使用条款。 |
| 芝加哥艺术博物馆 | [官方接口](https://api.artic.edu/docs/)；仅对明确标记开放授权的作品按对应条款使用。 |
| 克利夫兰艺术博物馆 | [开放馆藏](https://www.clevelandart.org/open-access)；核对每件作品的许可，不将开放政策推及所有内容。 |
| 小红书（隐藏） | 通过用户安装的 OpenCLI 与自有浏览器会话读取；不打包 Cookie、扩展或素材，遵守原平台规则和作者许可。 |
| 本地历史 | 读取用户本地图片与元数据；权利取决于原素材来源，保存到本地不改变授权。 |

详情保留可获得的作者、来源链接与权利字段；上游缺失字段时不能推断为公共领域。涉及侵权内容，请向原发布者或平台提交权利请求；本地缓存由使用者自行管理。
