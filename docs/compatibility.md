# 兼容性与验证范围

## 环境要求

| 组件 | 范围 | 说明 |
| --- | --- | --- |
| Python | 3.10+ | CI 目标为 Windows / Ubuntu 的 3.10、3.13；不把未跑过的组合标为通过。 |
| ComfyUI | 需 DOM widget、扩展注册和 aiohttp 路由接口 | 保持原节点 ID 和零输出模式；不同前端版本仍需实机验证。 |
| Node | 开发用 20.19+ / 22.12+ | jsdom 27 要求这些最低版本；运行节点不需要 Node。 |
| 浏览器 | 现代 Chromium | ComfyUI 可用 Chrome 或 Edge 打开；隐藏的小红书桥接需单独 Chrome 会话。 |
| 系统 | Windows、Linux | 路径通过 ComfyUI 输出目录解析，不固定盘符。 |

## 升级与回退

替换插件目录后重启 ComfyUI，并强制刷新前端。下载与索引保持在 `<ComfyUI>/output/ty-node/ty-image-spider/`；配置在本地 `.local/` 或环境变量中。升级包不含这些用户数据，不要覆盖或删除用户自己的目录。

2.5.0 保持 2.4.0 工作流 ID、来源 ID 和请求成功包络。缓存任务运行状态不跨进程恢复，分页断点持久保留；同条件任务返回 409 及现有 job_id，不同条件默认最多并行 3 个。每个 JSON 写入请求上限 1 MiB。需要回退时先停止缓存任务并备份用户数据，再使用之前版本代码。
