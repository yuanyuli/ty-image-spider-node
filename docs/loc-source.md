# 美国国会图书馆素材源

2.3.0 接入美国国会图书馆（Library of Congress）公开图片接口，无需注册、密钥或浏览器扩展，继续使用现有工作流。

## 浏览与搜索

节点提供纪实摄影、经典海报、历史人像、建筑档案、旅行海报、时尚摄影、日本版画和全部图片八个中文分类。分类使用官方 `partof`、`subject` 与在线图片筛选；旅行、时尚和日本版画使用预设英文查询。输入英文关键词后会在当前分类内继续缩小结果。

每页向官方接口请求24项，并过滤没有安全图片地址的记录，所以部分页面的可见卡片可能少于24张。上一页、下一页和缓存断点使用官方页码，不会因为当前页过滤后数量较少而提前结束。

## 图片与下载

搜索结果通常提供150、640、1024像素等多个版本。画廊优先使用不超过800像素的预览，详情与下载使用来源提供的最大版本。只接受 `tile.loc.gov` 图片地址，跳转到其他域名会被拒绝。

详情展示标题、作者或贡献者、日期、媒介、主题、说明与官方权利声明。下载保存到 ComfyUI 输出目录下的 `output/ty-node/ty-image-spider/loc/`；“新增缓存100张”保存预览、详情和索引，原图按需下载。

## 使用边界

馆藏中既有“无已知限制”作品，也有需要进一步核对的材料。节点不会把所有图片统一标记为公共领域；使用前以每件作品详情中的官方说明和来源页面为准。

接口依据：[Library of Congress JSON/YAML API](https://www.loc.gov/apis/json-and-yaml/)。

2026-09-20 实测首两页各24项且无重复，完成真实 JPG 下载与新增缓存100项，缓存任务无失败。公开接口偶发截断 JSON 时只重试一次，持续异常仍会向节点报告错误。
