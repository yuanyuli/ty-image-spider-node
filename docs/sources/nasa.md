# NASA 图片素材源

2.4.0 接入 NASA Image and Video Library 官方公开接口。无需账号、API 密钥或浏览器扩展，继续使用现有工作流。

## 浏览与检索

节点提供太空影像、地球观测、月球、火星、阿波罗计划、太空望远镜、宇航员、NASA 海报和全部图片分类。中文分类会映射为 NASA 接口使用的英文查询；还可以追加任务、天体、人物等英文关键词。

每页请求24项，并只保留图片媒体。上下页使用 NASA 的真实页码；接口报告总数后，节点据此决定是否显示下一页。

## 图片、详情与下载

画廊从来源提供的规格中选择不超过800像素的最大预览。详情与下载优先使用 NASA 标记为 `canonical` 的受支持原图，并只接受 `images-assets.nasa.gov` 的 HTTPS 图片地址。

详情保留日期、摄影者或 NASA 中心、关键词、说明、相册和 NASA Image ID。来源 ID 含空格或其他文件名不安全字符时，会转换为可读短名并追加12位摘要，防止不同素材互相覆盖。

“新增缓存100张”跳过已有素材并从当前条件的断点继续，每项缓存预览与结构化详情；高清原图按需下载。手动下载保存在：

```text
<ComfyUI 输出目录>/ty-node/ty-image-spider/nasa/
```

缓存和索引仍保存在 `<ComfyUI 输出目录>/ty-node/ty-image-spider/cache/`，实际根目录由 `folder_paths.get_output_directory()` 决定，不绑定盘符。

## 使用边界

NASA 图片库包含不同任务、合作机构和历史时期的材料。节点不会把所有条目统一声明为公共领域；使用、署名和再发布前，应查看详情中的说明及 NASA 来源页。

视频和音频资源不在本节点范围内。图片链接若跳转到未允许的站点，或响应不是可解码的 JPEG、PNG、WebP、GIF，会被下载器拒绝。
