# 视频素材源

2.7.0 新增独立“视频素材”分组，接入 Prelinger Archives、Wikimedia Commons 视频和 NASA 视频。三家均使用公开接口，无需 API Key、账号或浏览器扩展；节点保持零输出端口，视频只在节点详情中播放或下载。

## 来源与检索

| 来源 | 适合内容 | 检索和分页 | 媒体格式 |
| --- | --- | --- | --- |
| Prelinger Archives | 经典广告、工业、教育与文化档案影片 | 英文关键词；热门、最新、最早、相关排序；页码分页 | MP4 |
| Wikimedia Commons 视频 | 电影、动画、科学、自然与开放许可影像 | 中文或英文关键词；MediaWiki 游标分页 | MP4、WebM、Ogg |
| NASA 视频 | 太空、地球、月球、火星、阿波罗、望远镜和宇航员 | 中文分类叠加英文关键词；页码分页 | MP4 |

搜索结果卡片只加载静态封面，不在画廊中创建播放器。打开详情后才创建一个原生浏览器播放器，并优先选择适合在线预览的资源；关闭详情时会停止播放、移除媒体地址并释放播放器。

## 播放、下载与缓存

视频下载保存到 `<ComfyUI 输出目录>/ty-node/ty-image-spider/<来源>/`。下载器只接受来源声明的 HTTPS 主机，校验重定向、文件签名、输出路径和响应大小，单个文件上限为 2 GiB；完成写入前使用临时文件，已有且格式有效的同名视频会直接复用。

三个视频来源均不支持整页批量下载。详情中的“下载视频”和 `↓` 快捷键保存当前视频；`←`、`→` 切换本页相邻素材。下载进行中会忽略重复按钮和按键，失败后可以再次执行。

**视频缓存只保存封面和资料**。每次“新增缓存100条”跳过已有素材，继续保存最多100条静态封面、结构化详情和索引，不会在后台下载视频文件。视频仅在用户打开详情或明确下载时访问媒体地址。

## 浏览器兼容边界

播放能力取决于当前浏览器、操作系统和媒体编码。Chrome、Edge 等 Chromium 浏览器通常可直接播放 MP4；部分 WebM 或 Ogg 编码可能只能下载，详情会保留“当前视频暂不可播放”和可用下载规格。节点不会转码，也不会自动播放。

来源可能提供多个清晰度。播放器资源与下载资源分别选择：预览优先浏览器友好的中等规格，下载优先来源提供的最高质量文件。原始文件超过 2 GiB、响应缺少受支持签名或重定向到未授权主机时会被拒绝。

## 使用权利

- Prelinger Archives 条目的许可、署名和再使用条件并不完全相同，应逐项核对 Internet Archive 详情页中的 Rights 与 License URL。
- Wikimedia Commons 视频通常带有开放许可，但可能要求署名、相同方式共享或遵守其他条件，应逐项核对详情中的许可名称、链接与署名要求。
- NASA 视频仍可能包含合作机构素材、人物肖像、音乐、标识或第三方内容，应逐项核对 NASA 来源页与媒体使用规范。

本项目代码的 MIT 许可不覆盖下载的视频、封面、文字说明或商标。公开可访问也不等于允许商业使用、再分发或训练。
